# The Artisan Brew - Premium Cafe & Restaurant Demo Website

A modern, responsive, and elegant demo website built for cafes, bistros, and restaurants. Designed with clean typography, smooth animations, and a warm artisanal aesthetic.

## 🌟 Live Pages Included

- **Home (`index.html`)**: Hero section with CTAs, specialties cards, why choose us section, testimonials, and footer.
- **Menu (`menu.html`)**: Category filterable menu (Coffee, Breakfast, Burgers, Pizza, Desserts, Drinks) with prices and descriptions.
- **About (`about.html`)**: Cafe story, mission & values, animated statistics, and milestone timeline.
- **Gallery (`gallery.html`)**: Filterable photo gallery with an interactive modal lightbox viewer.
- **Contact (`contact.html`)**: Booking & inquiry form with validation, operating hours, WhatsApp CTA, and Google Map.

## 🛠️ Tech Stack

- **HTML5**: Semantic and accessible markup.
- **CSS3**: Custom CSS variables, flexbox/grid layout, smooth keyframe animations, and mobile-first responsiveness.
- **JavaScript (ES6+)**: Vanilla JS for dynamic category filtering, lightbox image viewer, intersection scroll observers, animated counters, and interactive forms.
- **Google Fonts**: *Playfair Display* & *Inter*.
- **Unsplash**: High-resolution, royalty-free photography.

## 🚀 Getting Started

Simply clone the repository and open `index.html` in your browser or run a live server:
